If Maya asks

Quick answers, not scripted lines

"Does it work with another LLM, not just Azure?"

Yes at the configuration layer — OpenAI and Azure AI Foundry are already built in, today's sidebar just has Azure switched on. Enabling a second option is a small change, not new development.

"Can this run in our CI pipeline, not just this UI?"

Yes — the same four metrics run from an automated pytest suite into the same report you just saw. UI for ad-hoc checks, pytest for "run on every merge."

"What if our API doesn't return JSON in this shape?"

Most common shapes auto-detect; a manual field-mapping panel (with dotted-path support for nested fields) covers the rest — a five-minute setup, not an integration project.

"What does POOR vs. MODERATE actually mean?"

A fixed scale, not a vibe: EXCELLENT ≥ 0.85, GOOD ≥ 0.70, MODERATE ≥ 0.50, POOR below — same four bands on every score, every run.
